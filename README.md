# Bangalore Traffic Congestion Prediction 🚦

## Project Overview
This project uses Machine Learning to predict traffic congestion levels in different areas of Bangalore based on traffic volume, average speed, weather conditions, incident reports, and other traffic-related factors.

## Machine Learning Algorithms
- K-Nearest Neighbors (KNN)
- Decision Tree Regressor
- Linear Regression

## Model Optimization
Used GridSearchCV to tune Decision Tree hyperparameters and improve model performance.

## Model Evaluation
Evaluated models using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Deployment
Deployed the trained model using Streamlit to provide an interactive interface for predicting traffic congestion.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Pickle, Streamlit, Jupyter Notebook, VS Code.
